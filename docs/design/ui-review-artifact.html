디자인 방향

A안 "계기판(Instrument)" — 하단 28px 상태바를 런타임 계기판으로 만든 것이 시그니처입니다. 모델 상태점 · 백엔드 · tok/s · 토큰 · 컨텍스트를 모노스페이스 수치로 상시 표시하고, 생성 중에는 속도 값이 강조색으로 갱신됩니다. 넓은 면적은 뉴트럴로 유지하고 teal(정상·주 동작), amber(재로드·주의), red(오류·삭제)를 기능적으로만 배분합니다. 중첩 카드·그라데이션·8px 초과 라운드·장식 그림자는 쓰지 않습니다.
