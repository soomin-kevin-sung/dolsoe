# Claude 디자인·아이콘 지시서

이 문서는 `dolsoe`의 시각 디자인과 앱 아이콘을 Claude에게 의뢰할 때 그대로 전달한다. Claude는 기술 구조나 제품 범위를 변경하지 않고 디자인 산출물만 만든다.

## Claude에게 전달할 요청

```text
당신은 Windows 데스크톱 생산성 앱의 시니어 프로덕트 디자이너다.

현재 저장소의 다음 설계서를 먼저 읽어라.
- docs/superpowers/specs/2026-07-18-local-llm-desktop-mvp-design.md

목표:
로컬 GGUF 모델과 대화하고 CPU/CUDA/Vulkan 런타임을 관리하는 Tauri 데스크톱 앱 "돌쇠"의 UI 디자인 시스템, 핵심 화면, 상태별 동작, 앱 아이콘을 설계한다. 디자인만 수행하고 애플리케이션 구현 파일은 수정하지 않는다.

제품 성격:
- 조용하고 전문적인 로컬 AI 작업 도구
- 기술 정보는 충분히 제공하지만 평상시에는 복잡하지 않아야 함
- 개인정보와 로컬 실행 상태가 명확히 느껴져야 함
- 마케팅 랜딩 페이지가 아니라 앱을 열자마자 실제 채팅 작업 공간이 보여야 함

필수 레이아웃:
- 왼쪽: 새 대화, 검색, 대화 목록, 요청 실행 상태
- 중앙: 메시지, 스트리밍 답변, 입력창, 생성 중지
- 오른쪽 또는 오버레이: 모델, backend, 장치, 기본·고급 설정
- 하단 상태 영역: 모델 상태, backend, tokens/s, context 사용량
- 별도 진단 화면: 앱/ABI/llama.cpp/런타임 팩/드라이버/메트릭

반드시 디자인할 상태:
- 첫 실행 및 모델 미선택
- 로컬 GGUF 선택
- CPU만 사용 가능한 상태
- CUDA/Vulkan 팩 설치 제안과 설치 진행
- 모델 로딩 진행률
- 준비 완료
- 단일 대화 생성과 스트리밍
- 여러 대화에서 동시 생성 중인 상태
- 생성 취소
- 모델 로드 실패, 메모리 부족, backend 초기화 실패
- 모델 재로드가 필요한 설정 변경 확인
- 기본 설정과 검색 가능한 고급 설정
- 로컬 텔레메트리 상세 화면
- 빈 대화, 대화 초기화, 삭제 확인

시각 원칙:
- Windows 11 x64 데스크톱을 우선하되 macOS 확장 가능성을 해치지 말 것
- 중첩 카드와 장식적인 카드 남용 금지
- 큰 마케팅형 헤드라인, 과도한 라운드, 그라디언트 오브, 보라색 중심 팔레트 금지
- 정보 밀도가 높은 도구에 맞는 정돈된 간격과 명확한 계층 사용
- 긴 모델 파일명, 긴 한국어·영어 토큰, 1024x700의 작은 창에서도 겹침이 없어야 함
- 아이콘 버튼에는 Lucide 아이콘을 기준으로 하고 낯선 아이콘에는 tooltip 제공
- 모든 사용자 문구는 한국어를 기본으로 작성
- 밝은 테마를 우선하고 어두운 테마 토큰도 함께 정의
- 접근 가능한 대비, 키보드 focus, loading/error/disabled 상태를 명시

권장 분위기:
- 중립적인 흰색과 회색을 기반으로 청록 또는 녹색 계열을 제한된 상태 강조색으로 사용
- 경고와 성능 정보에는 별도의 호박색 계열을 사용
- 색 하나로 화면 전체를 지배하지 말고 기능적 의미에 따라 배분
- 기술적이지만 차갑거나 게임 런처처럼 보이지 않게 할 것

UI 산출물:
1. 디자인 방향 3개를 간단히 비교하고 하나를 추천
2. 선택 방향의 색상, 타이포그래피, 간격, 반경, 그림자, 상태 색상 토큰
3. 1440x900 기준 메인 채팅 화면 고해상도 목업
4. 1024x700 기준 작은 창 목업
5. 첫 실행/모델 없음, 모델 로딩, 스트리밍, 동시 생성, 오류 상태 목업
6. 기본·고급 설정과 로컬 텔레메트리 화면 목업
7. 상호작용 및 전환 규칙
8. 컴포넌트 상태표
9. 개발자가 구현할 수 있는 치수와 동작이 포함된 handoff 문서

저장 위치:
- docs/design/claude-ui-spec.md
- docs/design/mockups/ 아래 이미지

앱 아이콘:
- 일반적인 챗봇 말풍선이나 로봇 얼굴은 사용하지 말 것
- "로컬 지식"과 "개인 장치에서 실행되는 추론"을 하나의 단순한 상징으로 결합할 것
- 16px에서도 식별 가능한 굵은 실루엣과 제한된 색상 사용
- 글자, 작은 노드, 가는 선, 사진 질감, 복잡한 배경 금지
- Windows 타일과 macOS 아이콘 모두에 맞도록 중앙 안전 영역을 확보
- 투명 배경의 1024x1024 PNG 원본을 만들 것
- 단색 및 어두운 배경용 변형도 제시할 것
- 최종 선택 전 서로 다른 개념 3개를 나란히 제안할 것

아이콘 산출물 저장 위치:
- docs/design/icon-concepts.png
- design/app-icon-1024.png

끝에 다음을 명확히 보고하라.
- 추천한 디자인 방향과 이유
- 미결정된 시각 선택
- 생성하거나 수정한 파일 목록
- Codex 구현자가 반드시 지켜야 할 핵심 치수와 상태 규칙
```

## 실행 순서

1. Claude에게 위 요청 전체를 전달한다.
2. Claude가 제안한 UI 방향 3개와 아이콘 개념 3개 중 하나씩 선택한다.
3. Claude가 최종 목업, UI 명세, 1024px 아이콘 원본을 저장한다.
4. Codex가 승인된 산출물을 기준으로 Tauri 앱을 스캐폴딩하고 구현한다.
5. 최종 PNG에 `cargo tauri icon design/app-icon-1024.png`를 적용해 플랫폼별 아이콘을 생성한다.
